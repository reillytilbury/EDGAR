# Documentation Guidelines

## 1. Style & Formatting
* Follow strict **Google Style** for all docstrings.

## 2. Module-Level Docstrings (File Headers)
* Every Python file must start with a module-level docstring at the absolute top of the file (before imports).
* It must include a brief description of the module's purpose within the codebase.
* It **must** include a `Usage Example:` section showing a realistic code snippet of how a human would import and use the primary functions/classes in this specific file.

## 3. Function and Class Docstrings
* Use `Args:`, `Returns:`, and `Raises:` headers where applicable.
* For the one-line summary, use a high-level description of what the function does without much technical detail.
* In the detailed summary, include equations used and algorithmic details.
