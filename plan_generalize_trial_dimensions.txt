# Plan: Generalize Trial Dimension Handling

## Context

The codebase currently enforces `inputs.shape[2] == outputs.shape[2]` (matching `n_trials`). This prevents experiments where input and output trial dimensions differ. The goal: **as long as an experiment can define a loss function given its inputs and outputs, the framework should work — regardless of whether trial dimensions match.**

The change introduces a per-experiment `sample_loss_fn(model, x_i, y_i, params) -> scalar` that gives the experiment full control over how loss is computed for a single sample. When not provided, the existing element-wise loss path is preserved for full backward compatibility.

### 3. Add `sample_loss_fn` parameter to `objective_vectorized`
**File:** `src/hypothesis_engine.py` (the `objective_vectorized` function, ~line 1036)

New optional parameter: `sample_loss_fn=None`

Signature contract for experiment-defined loss:
```python
def sample_loss_fn(model, x_i, y_i, params) -> scalar:
    """
    model: the JAX model function
    x_i: input for one sample, shape (n_features, n_trials_x)
    y_i: output for one sample, shape (n_targets, n_trials_y) or (n_trials_y,)
    params: 1D parameter array for this sample, shape (n_params,)
    Returns: scalar loss
    """
```

**When `sample_loss_fn` is provided:** use it directly as the per-sample loss
**When `sample_loss_fn` is None:** construct the default from `loss_func` (existing element-wise behavior)

```python
if sample_loss_fn is not None:
    def loss_single_sample(params, x_i, y_i):
        return sample_loss_fn(model, x_i, y_i, params)
else:
    # Existing element-wise path (unchanged)
    def loss_single_sample(params, x_i, y_i):
        pred = model_normalized(x_i, *params)
        elementwise_loss = loss_func(pred, y_i)
        per_target_mse = jnp.mean(elementwise_loss, axis=-1)
        return jnp.sum(target_weights * per_target_mse)
```

### 5. Update mini-batch loop for mismatched trials
**File:** `src/hypothesis_engine.py` (lines 1192-1225, 1307-1318)

Add a `trials_matched` flag:
```python
n_train_trials_x = x_train.shape[2]

```

- **Matched:** existing mini-batch code (batch x and y with same slices). Unchanged.
- **Mismatched:** disable trial mini-batching (pass full x_train, y_train). The custom `sample_loss_fn` handles the shape relationship internally.

Also disable the `use_scalar_single_feature_fullbatch` fast path when trials are mismatched (add `and trials_matched` to the condition at line 1194).
